MapMaker classroom speed test

How long each map takes to be ready when a whole class of students opens it at once over one shared classroom connection. A map is rated OK when 9 in 10 students have it ready within the time limit. Extra over MapMaker is how much longer the map takes than MapMaker's own default map, which is the fairest way to compare maps.
